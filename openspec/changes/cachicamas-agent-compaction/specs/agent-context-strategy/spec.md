## MODIFIED Requirements

### R-CTX-003 — "Never compacts" is a property of the ZERO VALUE, and the seam's teeth arrive only with an explicitly constructed request

The seam's verdict type MUST carry the compaction request as an **optional** value whose absence is its zero state. Concretely:

- The verdict's **zero value MUST request nothing**, on every path, in every door, forever. A strategy returning the zero verdict MUST cause no compaction, no compaction-family event, no history write and no provider call.
- A compaction MUST be requestable **only** by a strategy that explicitly constructs a request supplying its **own** model provider, its **own** options and its **own** instruction string. Layer 2 MUST NOT supply a default for any of the three (`R-CMP-002`).
- The request MUST also carry the boundary the strategy is asking for, denominated **in the transcript the prompt carried** — the only coordinate system the strategy can name, since `R-CTX-002` gives it Layer 1 messages and never harness state. Carrying a harness-internal identifier here would breach `R-CTX-002` and MUST NOT be done.
- The extension MUST be **non-breaking**: every implementation returning the zero verdict MUST keep compiling and MUST keep behaving exactly as it did before this change, the shipped never-compact default included.

**What is relaxed, and what replaces it.** AG-17 required the verdict type to expose "no field, no method and no constructor by which any implementation could request compaction", with its zero value its only constructible value. That made the never-compacts guarantee a property of the **type**, unfalsifiable by any strategy a caller could write. AG-18 necessarily gives the type a field, so that exact guarantee cannot survive. **It is replaced, not dropped**: the guarantee moves to the **zero value** — the strongest form still available once the extension point opens — and it is enforced by the same byte-identity pin `R-CTX-004` already runs, now re-scoped to every path on which no compaction is requested. An accept-flag the harness merely ignores would be strictly weaker and MUST NOT be shipped: the inertness must remain a property of the value, not of the harness's willingness to honour it.

`failover_policy.go:57-62` blessed exactly this extension path — *"A later version adds route and re-budget fields non-breakingly; every existing implementation returning the zero verdict keeps compiling"* — and **AG-18 is that later version**. Compaction is now constructible; it is no longer merely unimplemented.

The harness MUST act on a non-zero verdict in the turn-boundary gap in which it received it, and MUST NOT retain, queue or defer it to a later boundary. After a successful compaction the harness MUST rebuild the transcript it will send from the mutated history **before** entering the attempt loop, because the slice resolved earlier in that iteration (`harness.go:512`, re-verified this phase) is stale, and `R-RTY-002`'s by-reference reuse requires the attempt loop to receive the rebuilt slice **once, before any attempt**.

One shipped, installable never-compact default MUST exist, together with a compile-time guard that it satisfies the seam.

(Previously: "The seam's verdict type MUST expose **no field, no method and no constructor** by which any implementation could request compaction. Its zero value MUST be its only constructible value… The harness MUST receive the verdict and discard it, because nothing else exists to do with it. AG-17 MUST introduce **no** compaction branch, **no** compaction event emission, and **no** transcript surgery of any kind." AG-18 is the milestone that requirement named as its own amender.)

### R-CTX-004 — The inertness pin: requesting no compaction changes nothing observable

A run driven with the shipped never-compact default installed MUST be observationally indistinguishable from the identical run driven with the seam field nil.

**Indistinguishable is defined by two byte-level comparisons, both required**, because a loose comparison passes vacuously (`S-PRH-002`'s "the seam adds zero observable behavior when not installed" at `agent-pre-request-hook/spec.md:63`, `S-LSK-015` and `R-RUN-012`'s nil-default posture at `agent-run-driver/spec.md:295-302`):

1. the recorded **event streams** of the two runs MUST be byte-identical, and
2. the **transcript read back** through history's existing read-only route MUST be byte-identical between the two runs.

**On any path where no compaction is requested**, no compaction event MUST be emitted, and no history entry MUST be mutated, added or removed by the seam. On such a path the seam reads the transcript through the route the driver already uses (`transcriptFromHistory`, `harness.go:512`); it opens no new history route and takes no write path.

**What is relaxed, and what replaces it.** AG-17 stated the no-new-route, no-write-path clause unconditionally, because no request was constructible. AG-18 makes one constructible, so the clause is **re-scoped to every no-request path** rather than deleted — and it is re-proved there by the same byte-identical two-run comparison, unchanged. On a **requesting** path the write is the one route `R-HIS-001` as amended admits, and nothing else: the requesting path opens no second door, and every guarantee it relaxes is replaced in that requirement.

(Previously: "**No compaction event MUST be emitted on either run, and no history entry MUST be mutated, added or removed by the seam on either run.** The seam reads the transcript through the route the driver already uses…; it opens no new history route and takes no write path" — stated with no path qualifier, which AG-18's requesting path would have falsified.)
