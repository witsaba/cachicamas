## MODIFIED Requirements

### R-CAN-002 — An interrupt ends the run, not the harness value

An interrupt MUST wind the run down and MUST NOT end the harness value. The run MUST terminate with the **interrupted** run outcome and, per `RunEnd.validate`'s failure-iff-`Failed` rule (`run_events.go:156-161`), with **no** `*Failure` attached. It MUST NOT terminate as failed and MUST NOT carry `ai.FailureCategoryUnavailable`.

Wind-down MUST be, in order: synthesize orphans over the transcript; close the turn; **emit the run-scoped final cost figure**; emit the run-close event through the existing public run-event constructor; return an error matching the firing signal's sentinel. Orphan synthesis is idempotent (`R-HIS-008`), so a turn whose results were already committed synthesizes nothing and the ordering is safe on every path.

**The third step is AG-16's insertion, and it is stated as an amendment rather than absorbed silently.** Before returning, and **immediately before** the run-close, the wind-down MUST emit a `cost_session` carrying `CostLabelFinal` with the run's cumulative token figures at close time (`R-CST-005`, `R-CST-006`). The reason is not symmetry: tokens spent before a cancellation are **real spend**, and a cancelled run that reports nothing is indistinguishable at the consumer from a run that spent nothing. Four constraints bound the insertion:

- **Position is fixed.** It goes after the turn is closed — the turn bracket must already be closed, per the paragraph below — and immediately before the run-close, which remains the run bracket's **last** event. `cost_session` is `PlacementRun` (`event.go:332-334`), so the position is validator-legal, and `CheckStream` MUST accept the recorded wind-down stream **unmodified** with `stream_check.go` **byte-unchanged**.
- **It is best-effort.** If the payload cannot be constructed, the emission is skipped and the wind-down proceeds unchanged: the same run outcome, the same nil `*Failure`, the same returned error, the same sentinel. A cost emission MUST NOT convert an interrupted run into a failed one and MUST NOT attach a `*Failure` to a close that carries none.
- **It writes no transcript.** The emission is a stream event only; it appends nothing, synthesizes nothing, and does not re-run or re-order orphan synthesis.
- **It does not fire where no run bracket exists.** The post-shutdown refusal of `R-CAN-005` MUST continue to emit **no event whatsoever**, cost events explicitly included.

**The turn bracket MUST close before the run bracket does.** `CheckStream` rejects a run-close emitted while a turn bracket is still open, so the turn that observed the cancellation MUST emit its own turn-close first, carrying the **aborted** turn outcome and a `*Failure` of the pre-existing category `ai.FailureCategoryCancellation` — mirroring the mid-stream-fatal branch's existing precedent rather than introducing a path of its own. No new `TurnOutcome` member is introduced: `turn_events.go` stays byte-unchanged (`S-LSK-018`). This is the **turn's** bracket only and does not weaken the rule above: the **run's** close still carries no `*Failure`. Recorded here because the two brackets carry deliberately different failure shapes, and a reader who assumes the run's nil-failure rule also governs the turn's close would read the emitted stream as malformed. **A cancelled turn closes aborted, so it emits no `cost_turn` at all** (`R-CST-001`, `R-LSK-001`'s AG-16 amendment); the run-scoped figure this requirement inserts carries the spend of the turns that closed **before** the signal, and no figure is invented for the aborted one.

After an interrupted run has returned, a subsequent `Run` on the **same harness value** MUST be accepted and MUST be able to complete normally, with the steering queue reopened at `Run` entry (`R-RUN-001` delta). This is the only cross-run behavior AG-14 introduced beyond the terminal shutdown flag of `R-CAN-005`. **The cumulative cost figure is run-scoped and MUST NOT survive the run**: a second run on the same harness value starts from nothing, because the harness value is serially reused and carries no cross-run state (`R-CST-004`).

**Cross-run transcript state: CLOSED by AG-21.** The clause this requirement carried — *"cross-run transcript state remains AG-21's"* — is discharged. The closed inventory of run-outliving `Harness` state, and the reason the claim is an **absence** rather than a presence, live in this change's `agent-run-driver` delta on `R-RUN-001`, which is where the cross-run clause is owned; this requirement inherits it. Two consequences bind **this** capability specifically:

- **The adversarial branch is the one that is asserted.** AG-21's cross-run driver ends run 1 through *this requirement's own wind-down*, mid-turn and over a genuinely open call, so orphan synthesis and the turn close really write into whatever transcript the run resolved. A cross-run claim proven over a cleanly completed run would never take this branch at all.
- **The cost row stays where it is.** The run-scoped figure is unchanged and remains proven by `S-CAN-013`; AG-21 adds no cost assertion and re-scopes no figure.

**AG-19 back-annotation — the enumerated tail is CLOSED against the first in-frame event producer, by a lifetime bound rather than by fixture luck.** AG-19 lets a tool publish admissible events onto its hosting run's lane from inside `tool.Run`. Three facts, stated so no later reader re-derives them:

- **No mirrored event can land inside this requirement's tail.** The publishing seam is revoked when the hosting tool call completes, on every exit path including detach and re-panic (`R-DEL-003`). A revoked publish returns typed and sends nothing. The call completes strictly before the turn closes, so every mirrored event is already on the lane before step 2 of the order above runs. Steps 2–5 are unreachable by a publisher.
- **A nested run's own wind-down obeys this requirement independently.** A child harness derives its run context from the tool's `ctx` (`harness.go:434`), so the parent's cause reaches it transitively — the tree AG-14 built, used rather than extended. The child winds down through **this same order** on its **own** lane, and its stream is `CheckStream`-validated **separately** from the parent's; the two are never concatenated (`R-DEL-005`).
- **Leaf-first is asserted by observed event order, never by elapsed time.** On the parent's lane the index of `subagent_ended` is strictly less than the index of the parent's run-close, and that ordering is structural: the tool publishes `subagent_ended` only after the child's sink closed, which happens only after the child's run-close was sent (`harness.go:446`). The parent's wind-down bound is set generously for that scenario — a **ceiling**, never a synchronization point, exactly as `NFR-CAN-002` already permits.

The requirement made no statement about a producer publishing onto the run's lane from inside a tool frame, because none existed; a reader meeting AG-19's seam could not tell from this requirement whether a late publish could land between the turn close and the run close.)

### R-CAN-005 — Shutdown winds down identically and then terminally refuses new prompts

Shutdown MUST perform the same wind-down as an interrupt (`R-CAN-002`), differing in exactly two observable ways: the run-end event MUST carry the **shutdown** run outcome (`R-CAN-007`), and the returned error MUST satisfy `errors.Is` against the shutdown sentinel and MUST NOT satisfy it against the interrupt sentinel.

**"The same wind-down" includes AG-16's inserted step, and the inheritance is stated rather than left to be inferred.** A shutdown wind-down MUST likewise emit the `cost_session` carrying `CostLabelFinal` immediately before its run-close, under the identical four constraints `R-CAN-002` states — fixed position, best-effort, no transcript write, and no emission where no run bracket exists. The two signals stay distinguishable by exactly the two observables named above; the cost figure is **not** a third discriminator and MUST NOT differ in shape between the two paths.

Shutdown MUST additionally latch a **terminal, one-way** refusal flag on the harness value. A `Run` invoked after shutdown MUST return the typed post-shutdown refusal (`R-CAN-001`), MUST emit no event whatsoever, and MUST leave the consumer sink in a state the caller can drain to completion. **"No event whatsoever" is absolute and now explicitly includes cost events**: the refusal opens no run bracket, so it emits no `cost_session`, no `cost_turn`, and nothing else. The flag MUST never resume a run and MUST hold no transcript: it is per-value terminal bookkeeping.

**The flag's place in the cross-run inventory: RECORDED by AG-21.** The clause this requirement carried — that the flag *"does not pre-empt AG-21's cross-run state"* — is discharged, and the discharge **confirms** the flag rather than narrowing it. The flag is one of exactly two rows in `R-RUN-001`'s closed inventory of run-outliving `Harness` state (the other being the session-start latch of `R-RUN-013`), and it is there for the reason this requirement already gives: it is terminal, one-way, holds no transcript and never resumes a run. Two consequences:

- **The flag is asserted as still unlatched on the interrupt path**, so a cross-run scenario ending run 1 by interrupt gets a second run that is **accepted** rather than refused — which is what makes the transcript claim reachable at all. A shutdown-ended run 1 tests the other side: the second `Run` is refused typed and emits nothing.
- **The flag is not a transcript carrier, and AG-21 does not make it one.** Nothing in this discharge lets the flag hold, resume or replay any run state; it remains exactly the one-way boolean fact `S-CAN-005` already proves.

The two signals MUST stay distinguishable **through both nouns of `0003:1379`** — the run-end outcome on the stream and the Go error chain — so a consumer that reads only the stream, such as a Layer 3 TUI holding no Go error, can still tell them apart.

(Previously: the requirement inherited a wind-down whose enumerated order carried no cost emission, and its "no event whatsoever" clause named no event class explicitly — so a reader could not tell whether a post-shutdown refusal was expected to report a zero cost figure or nothing at all.)

(Previously, at AG-21: the latch paragraph ended *"…it is per-value terminal bookkeeping and does not pre-empt AG-21's cross-run state (`agent-run-driver`'s `R-RUN-001`, its one-run-at-a-time clause)."* — an open forward reference. A reader could not tell whether the flag belonged to a settled inventory of run-outliving state or was merely provisionally tolerated until AG-21 decided.)
