## MODIFIED Requirements

### R-LSK-001 — Loop surface: single-turn function form (D1)

The system SHALL expose `func Turn(ctx context.Context, provider ai.ModelProvider, system string, transcript []ai.Message, opts TurnOptions, sink chan<- *Event) (msg ai.Message, finish ai.FinishReason, err error)` as the only public surface for one assistant turn (per D1, D2, D3). AG-13 introduces a value-form `Harness` that wraps `Turn` without changing its signature. `TurnOptions` carries a `Tools map[string]Tool` field for AG-09 (non-breaking zero-value extension; nil `Tools` = the scheduler returns typed `ExecutionFailure` results in their ordinal slots, consistent with R-TLS-009 "one bad tool does not abort the turn"). `TurnOptions` also carries the AG-08 `PreRequestHook` field (nil = identity default). `TurnOptions` further carries the AG-10 `PermissionPolicy PermissionPolicy` field (non-breaking zero-value extension). A **nil** `PermissionPolicy` is the identity default: the scheduler bypasses the permission gate, every call is treated as an immediate allow, no permission event is emitted, and the turn behaves exactly as it did before AG-10.  A non-nil policy MUST be forwarded byte-exact to `Schedule` and consulted for every scheduled call.

**AG-13 adds one further non-breaking, nil-default extension: `TurnOptions.Continuation`, the run-continuation seam.** It carries, as one all-or-nothing group, the four things a multi-turn run must share across turns: the caller-supplied run identity, the caller-owned lane stamper, the caller-owned scheduler, and the caller-owned transcript store. The grouping is normative: a half-configured continuation — a run identity without a stamper, say — silently breaks lane contiguity, so when the continuation is present every member MUST be present, and a partially configured continuation MUST be rejected typed **before any event is emitted**. `Turn`'s positional signature MUST NOT change; the documented "AG-13's later `Harness` can wrap it without changing the signature" contract is preserved literally.

With `Continuation` **nil**, every path through `Turn` MUST be byte-stable pre-AG-13 behavior — identity minted fresh, run brackets emitted unconditionally, a fresh per-call lane, a locally constructed scheduler, finalize-first ordering, and no transcript wiring. This is the whole of AG-13's compatibility claim and it is what makes every existing loop, hook, dispatch, termination and permission test pass **file-unchanged**. AG-15 did not weaken this: the pre-stream emission below is added on **both** paths, so "byte-stable pre-AG-13 behavior" was read as byte-stable **for everything except the pre-stream turn-close AG-15 adds**, which is an addition to the nil path as much as to the continuation path and is enumerated as such. **AG-16 amends this clause a second time, by the same discipline and with the same enumeration**: the per-turn cost emission below is likewise added on **both** paths, so the compatibility claim is now read as byte-stable for everything except (a) AG-15's pre-stream turn-close and (b) AG-16's `cost_turn`. Every deviation from pre-AG-13 behavior on the nil path is enumerated in this paragraph and nowhere else; an unenumerated deviation is a defect under this requirement.

With `Continuation` **non-nil**, `Turn` MUST behave as follows and in no other way:

1. It MUST join the supplied run identity instead of minting one, and MUST use the supplied lane stamper instead of creating one, so that N invocations share one contiguous 1-based lane. `TurnID` MUST still be minted fresh per invocation — N distinct turn brackets need N identities.
2. It MUST emit **no** run-open and **no** run-close event on **any** path, including the mid-stream fatal path and the three pre-stream failure paths, where the turn-close carrying the aborted outcome is still emitted. The run bracket belongs to the caller, because only the caller knows the run boundary: a terminal finish reason with a queued steering message does not close the run.
3. It MUST invoke the tool schedule **before** finalize, so that the turn's tool and permission events land inside the open turn bracket. This reorder is required, not cosmetic: every tool and permission descriptor is turn-placed, and the stream validator rejects a turn-placed event outside an open turn and rejects anything after the terminal run-close. The nil path MUST keep its finalize-first ordering byte-stable.
4. It MUST capture the rejoin results rather than discarding them — the `_ = sched.Schedule(...)` discard that `agent-turn-termination/spec.md:148` names as a pre-existing gap ends here, **on the continuation path only**.
5. It MUST reconstruct the turn's assistant message including the turn's tool-call parts with provider-exact bytes, so a pure-tool turn yields a constructible assistant message whose calls the transcript's pairing invariant can match.
6. It MUST wire the turn's own messages into the supplied transcript store. That obligation is owned by `R-HIS-010` in [`../agent-history/spec.md`](../agent-history/spec.md) and is stated there, not duplicated here.

The **signature is unchanged by AG-11**, but the returned-value contract on the mid-stream-fatal path changes: when the provider stream ends in a terminal error, `Turn` MUST return the assistant message reconstructed from the content accumulated before the failure together with the non-nil error, rather than the zero `ai.Message{}` (`loop.go:275`). On that same path `Turn` MUST have emitted `turn_end`/`run_end` before closing the sink, per `R-ATT-005` — except on the continuation path, where per (2) above the run-close is suppressed and the run bracket's failure close is the caller's (`R-RUN-011`). On every successful path `Turn` MUST return a `finish` that is a member of `ai.FinishReason`'s vocabulary, including the provider-closed-without-`Completion` path, where `ai.FinishReasonStop` remains the documented fallback.

**AG-15 adds the pre-stream half of that emission contract, which has been missing since AG-07.** Once `turn_start` has been emitted, **every** failure exit of `Turn` MUST close the turn bracket it opened. Concretely, each of the three pre-stream failure paths — the request-build error, the pre-request-hook error, and the `provider.Stream` error — MUST emit a `turn_end` carrying `TurnOutcomeAborted` and a **non-nil** `*Failure` **before** closing the sink, mirroring the mid-stream path (`loop.go:398-400`, `R-ATT-005`). The run-close obligation splits by path exactly as the mid-stream case already splits it: on the **nil-continuation** path a `run_end` carrying `RunOutcomeFailed` and the same `*Failure` MUST follow the turn-close; on the **continuation** path the run-close MUST NOT be emitted, because point (2) above gives the run bracket to the caller. A consumer MUST NOT observe the sink close with the turn bracket still open.

Three consequences are stated rather than left to be inferred:

- **The build path returns a plain Go error, so the emission needs a wrap.** `TurnEnd.validate`'s failure-iff-aborted rule requires a non-nil `*Failure` (`turn_events.go:123-128`), and that rule MUST NOT change. A cause that already is an `*ai.Failure` — the hook path's typed pre-stream failure (`loop.go:319-322`) and whatever the provider returned (`loop.go:332-338`) — MUST be wrapped **as itself**, preserving its category, retryability, retry-after, partial-output and delivery readings; a plain Go error MUST be wrapped as a **pre-stream** failure, because a pre-stream abort truthfully crossed no carrier. One helper serves all three call sites.
- **No substrate release is requested by AG-15, and that conclusion is recorded rather than inferred.** The emission uses the **existing** `NewTurnEnd` and `NewRunEnd` constructors, adds no `TurnOutcome` member and registers no `EventKind`, so `turn_events.go`, `failure.go`, `run_events.go`, `event.go` and `stream_check.go` all stay **byte-unchanged**. `R-LSK-004`'s AG-11-only release is **not** extended to AG-15.
- **Best-effort posture, matching the mid-stream block.** If the wrap or a constructor fails, the emission is skipped and the path's original error is still returned unchanged — the `ferr == nil` / `terr == nil` guard posture already at `loop.go:388-404`. The emission must never convert a typed pre-stream failure into a different error.

**AG-16 adds a per-turn cost emission to the same contract, and it changes the closed nil-path sequence.** A turn that closes **non-aborted** MUST emit a `cost_turn` event on `sink`, **inside the turn bracket it opened and before that bracket's `turn_end`**, carrying the turn's five token figures with per-figure presence taken from whatever the stream reported — possibly nothing. This holds on **both** the nil-continuation and the continuation path, and on both `finalize()` call paths. The emission's *content* rules — the always-`Final` label, the per-figure presence semantics, and the absent-vs-reported-nought distinction — are owned by [`../agent-cost-events/spec.md`](../agent-cost-events/spec.md) (`R-CST-001`, `R-CST-002`) and are not duplicated here.

Four consequences, stated rather than left to be inferred:

- **The rule is an iff, and the aborted half is as binding as the emitting half.** A turn that closes **aborted** MUST NOT emit a `cost_turn`: not the mid-stream fatal path, not any of AG-15's three pre-stream paths, and not the cancellation path — none of the three has a usage source at all (`Completion` is `Terminal`; `ai.Failure` carries no usage, `provider_failure.go:320-330`), and inventing five zeros for them is exactly the defect the charter's acceptance text forbids (`0003:1535`).
- **Placement, not convention.** `cost_turn` is registered `PlacementTurn` (`event.go:329-331`); `CheckStream` rejects a turn-placed event outside an open turn (`stream_check.go:161-163`) and the bracket closes at `turn_end` (`:147-155`). The emission MUST therefore precede `turn_end` on every path that emits one. `CheckStream` MUST accept the recorded stream **unmodified**, with `stream_check.go` **byte-unchanged** — the fix lands on the emitter, never the validator (`R-RUN-003`).
- **The signature stays frozen.** `Turn` returns no usage and gains no parameter: the usage reaches the emission site through the turn's own accumulator. `agent-turn-termination/spec.md:113` and `NFR-ATT-004` **hold unamended**, which is checked, not assumed, by that capability's back-annotation delta.
- **Best-effort posture, matching the two blocks above.** If the payload cannot be constructed, the emission is skipped and the turn's own outcome, returned values and remaining event sequence are unchanged. A cost emission MUST NOT convert one turn outcome into another and MUST NOT change what `Turn` returns.

`Turn` MUST NOT expose the scheduler or any wake handle **through its return values or its signature**; that remains true at AG-13. AG-10's stronger statement — "`Turn` MUST NOT expose the scheduler or any wake handle at this milestone — `Scheduler.WakeParked` is unreachable from a `Turn` caller, and wiring the upward-path wake is AG-13's scope" — was scoped to AG-10 and is **now closed**: AG-13 makes the wake reachable by letting the caller **inject** a scheduler it already owns, never by handing one back. A caller that supplies no continuation still cannot reach a scheduler.

(Previously: `Turn` discarded `completion.Usage()` at its Completion case and emitted nothing carrying token figures on any path, so the nil-path turn sequence ended `…, turn_end, run_end` with no cost event anywhere in it, and a run's token spend was unobservable from the stream. The pre-AG-13 compatibility clause enumerated one AG-15 exception and no AG-16 exception.)
