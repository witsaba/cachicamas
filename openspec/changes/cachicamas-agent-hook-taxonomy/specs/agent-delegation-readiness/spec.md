## ADDED Requirements

### R-DEL-011 — AG-20's observing hooks CANNOT reach the publishing seam, and the fence passes unedited

**Two claims, and only the second is a back-annotation.**

**Claim 1 — the seam is unreachable from an observing hook, BY CONSTRUCTION rather than by convention.** AG-20 introduces observing hooks that are invoked asynchronously, on a lane goroutine, and which may run **after `Run` has returned**. Their invocation context MUST be freshly rooted and **value-stripped**: neither the run context nor a cancellation-stripped derivation of it.

The reason is specific to this capability and MUST be recorded here rather than only in the hook spec, because this is where a reader greps for it. A cancellation-stripped derivation preserves context **values**. In a hosted child run — exactly the arrangement `R-DEL-001` blesses — the child's run context **inherits the hosting tool call's publishing seam**, installed by the scheduler's per-call installation and retrievable by the plain value lookup at `delegation_seam.go:101-104`. A value-preserving observer context would therefore hand an **observing** hook the one sanctioned door back onto the **parent's** event lane, and it would do so asynchronously, after the hosting call had returned and possibly after `Run` had. Three shipped properties would be at risk at once: `R-DEL-003`'s lifetime bound (a publish after the hosting call returned), `R-AGE-008`'s no-path-back trace (an observer reaching a producer), and `R-HKS-001`'s "an observer cannot signal a mutation" (an observer mutating a stream).

The seam's own defences would have caught the *consequence* — `R-DEL-003`'s revocation returns the revoked sentinel rather than panicking or dropping silently — but a hook holding a live-looking door and receiving a sentinel is a design that **invites** the attempt. Value-stripping removes the door instead, and makes the hook capability's "unconstructible" claim literally true rather than defended in depth.

**Claim 2 (back-annotation) — the fence and the closed-sequence table both hold, unedited and unmoved.** AG-20 registers **no** `EventKind`: the stalled-observer report is a Go-side typed value delivered off the streaming path, decided **structurally** — an event announcing the stall is itself a path from the stalled observer back to the producer, which `S-AGE-010` forbids — rather than on the seven-site budget argument. It adds **no** `Harness` method: the registration surface is a field, so `scope_fence_test.go:102-105` and `harness_test.go:1031` both pass **unedited**. And it emits nothing on any path, so every row of `R-DEL-010`'s table keeps its verdict and its mechanism.

**What this requirement does NOT claim.** It does not extend the seam, widen its admissibility rule, or give any hook a publishing capability. It does not make a **mutating** hook value-stripped: mutating hooks keep the live context on the caller's goroutine exactly as AG-08 shipped, which is correct precisely because they run **inside** the frame whose context they receive. And it does not close `R-AGS-006`'s deferred subagent-tool entry, which AG-20 does not touch.
