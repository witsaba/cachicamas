## ADDED Requirements

### R-LSK-008 — AG-20 requests NO substrate release, and its guard-filter widening is enumerated by name

**AG-20 requests NO release from `R-LSK-004`, and that conclusion is recorded rather than inferred — the AG-15, AG-17 and AG-19 shape, not the AG-16 or AG-18 shape.** AG-20 modifies **`loop.go`, `harness.go` and `compaction.go`** and creates one production file (`hooks.go`) plus three test files in `package agent_test`, all under `backend/agent/src/agent/`. **None of those three modified files is a member of `R-LSK-004`'s forbidden list**, and neither is any file AG-20 creates. Seven consequences MUST be stated rather than left to be inferred:

1. **No `EventKind`, so no event file opens — and the reason is structural rather than budgetary.** AG-20 registers **none**. The stalled-observer report is a Go-side typed value delivered off the streaming path, because an event announcing the stall **is** a path from the stalled observer back onto the producer's stream, which is exactly what `S-AGE-010` forbids and exactly the invariant AG-20.2 exists to close. `event.go`, `event_descriptor.go`, `event_registry_test.go`, `compaction_events.go`, `delegation_events.go`, `permission_events.go` and `cost_events.go` MUST all be byte-unchanged, and the event-kind guard MUST pass at its committed kind count.
2. **The stall types live in `hooks.go`, NOT in `failure.go`, and the placement is DECLINED explicitly rather than left to convenience.** `failure.go` is on `R-LSK-004`'s forbidden list. Declaring the stall report there would pass the mechanical filter check silently — the guards compare filenames, not intent — while violating the requirement's prose. `failure.go` MUST be byte-unchanged.
3. **No validator edit, because the observer lane emits nothing.** `stream_check.go` MUST be byte-unchanged. The lane holds no sink, stamps no event and touches no sequence; a run with observers registered produces a byte-identical stream to the same run without them (`R-HKS-007`). The fix is emitter-side by construction, never validator-side (`R-RUN-003`).
4. **No NEW package-wide guarantee FOR THE HOOK SURFACE ITSELF, so the contract table gains no new row for it.** AG-20 declares no `L2C` row of its own: it adds no upward surface beyond the existing stream (`L2C-03`) and no exported `History` route (`L2C-07`), and its shipped default is inert **by type**. `expectedLayer2ContractRows` MUST keep exactly the row COUNT and the row SET's own identities it carries at the merge base — no row added, no row removed. **AG-15's failover seam, AG-17's strategy seam and AG-19's publishing seam are the decisive precedents**: structurally identical — a caller-invisible seam with an inert default — and none added a row. **This is unrelated to, and unweakened by, consequence 7 below**: an EXISTING row (`L2C-08`, owned by `agent-cancellation-tree`, not by this delta) was AMENDED during `sdd-verify` for a reason that has nothing to do with the hook taxonomy's own upward surface — the observer lane's goroutine lifetime, not anything it publishes. `doc.go` and `doc_contract_guard_test.go` are consequently NOT byte-unchanged overall, even though this consequence's own reason for touching them never fired.
5. **No cost, history, scheduler or Layer 1 file opens.** `cost_events.go` (released for AG-16 only), `cost_events_test.go`, `cost_usage.go`, `history.go`, `sequence.go`, `run_events.go`, `turn_events.go`, `reconstruction_test.go`, `scheduler.go`, `tool.go`, `delegation_seam.go`, `go.mod` and `go.sum` MUST be byte-unchanged, as MUST every file under `backend/agent/src/ai/` and every file under `backend/agent/src/agenttest/` — the test gate primitive is **used**, not widened. AG-11's, AG-14's, AG-16's and AG-18's releases are **not** extended to AG-20: every file named forbidden in `R-LSK-004` is forbidden again here. **`scope_fence_test.go` and `cancellation_test.go` are each released, narrowly, per consequence 6 below — the one entry this paragraph deliberately no longer names.**
