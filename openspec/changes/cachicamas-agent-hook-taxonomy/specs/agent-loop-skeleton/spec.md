## ADDED Requirements

### R-LSK-008 — AG-20 requests NO substrate release, and its guard-filter widening is enumerated by name

**AG-20 requests NO release from `R-LSK-004`, and that conclusion is recorded rather than inferred — the AG-15, AG-17 and AG-19 shape, not the AG-16 or AG-18 shape.** AG-20 modifies **`loop.go`, `harness.go` and `compaction.go`** and creates one production file (`hooks.go`) plus three test files in `package agent_test`, all under `backend/agent/src/agent/`. **None of those three modified files is a member of `R-LSK-004`'s forbidden list**, and neither is any file AG-20 creates. Five consequences MUST be stated rather than left to be inferred:

1. **No `EventKind`, so no event file opens — and the reason is structural rather than budgetary.** AG-20 registers **none**. The stalled-observer report is a Go-side typed value delivered off the streaming path, because an event announcing the stall **is** a path from the stalled observer back onto the producer's stream, which is exactly what `S-AGE-010` forbids and exactly the invariant AG-20.2 exists to close. `event.go`, `event_descriptor.go`, `event_registry_test.go`, `compaction_events.go`, `delegation_events.go`, `permission_events.go` and `cost_events.go` MUST all be byte-unchanged, and the event-kind guard MUST pass at its committed kind count.
2. **The stall types live in `hooks.go`, NOT in `failure.go`, and the placement is DECLINED explicitly rather than left to convenience.** `failure.go` is on `R-LSK-004`'s forbidden list. Declaring the stall report there would pass the mechanical filter check silently — the guards compare filenames, not intent — while violating the requirement's prose. `failure.go` MUST be byte-unchanged.
3. **No validator edit, because the observer lane emits nothing.** `stream_check.go` MUST be byte-unchanged. The lane holds no sink, stamps no event and touches no sequence; a run with observers registered produces a byte-identical stream to the same run without them (`R-HKS-007`). The fix is emitter-side by construction, never validator-side (`R-RUN-003`).
4. **No new package-wide guarantee, so the contract table stays closed.** AG-20 declares no `L2C` row: it adds no upward surface beyond the existing stream (`L2C-03`) and no exported `History` route (`L2C-07`), and its shipped default is inert **by type**. `doc.go` and `doc_contract_guard_test.go` MUST be byte-unchanged and `expectedLayer2ContractRows` MUST keep exactly the row set it carries at the merge base. **AG-15's failover seam, AG-17's strategy seam and AG-19's publishing seam are the decisive precedents**: structurally identical — a caller-invisible seam with an inert default — and none added a row.
5. **No cost, history, scheduler or Layer 1 file opens.** `cost_events.go` (released for AG-16 only), `cost_events_test.go`, `cost_usage.go`, `history.go`, `sequence.go`, `run_events.go`, `turn_events.go`, `reconstruction_test.go`, `scheduler.go`, `tool.go`, `delegation_seam.go`, `scope_fence_test.go`, `go.mod` and `go.sum` MUST be byte-unchanged, as MUST every file under `backend/agent/src/ai/` and every file under `backend/agent/src/agenttest/` — the test gate primitive is **used**, not widened. AG-11's, AG-14's, AG-16's, AG-18's and AG-19's releases are **not** extended to AG-20: every file named forbidden in `R-LSK-004` is forbidden again here.

**The same widening discipline binds AG-20, and its additions are enumerated BY NAME and NEVER BY COUNT**, because a count goes silently false the moment a later milestone appends — the property `S-LSK-020` exists to protect. `harness.go`, `harness_test.go`, `loop.go`, `loop_test.go`, `loop_hook_test.go`, `scheduler.go`, `tool.go`, `doc.go`, `doc_contract_guard_test.go` and every filename AG-19 added are **already** named in both substrate filters and need no addition — **so AG-20 adds no pre-existing filename, because it releases none.**

Both filters SHALL widen by one **exact filename suffix** for each of exactly these four:

- `/hooks.go`
- `/hooks_test.go`
- `/hooks_harness_test.go`
- `/hooks_compaction_test.go`

The **identical** four SHALL be added to **both** `filterOutLoopFiles` (`loop_test.go:837`) and `filterOutLoopHookFiles` (`loop_hook_test.go:907`). Adding to one and not the other is a defect this requirement forbids by name.

**Editing those two test files is MANDATORY, not optional, and it is NOT a release.** `compaction.go` is likewise **not** a member of the forbidden list, so its modification takes no release either. Without the four filter entries, `hooks.go` and its three test files would appear unstripped in the substrate-untouched guard's diff (`loop_test.go:1329-1335`) and the guard would fail on files the milestone is entitled to add. The edit is **confined to the two filter lists**: no assertion in either file changes, and AG-08's assertions in `loop_hook_test.go` are untouched. Both files are already named in both filters, so the fact that this change edits them is itself covered by the existing entries and constitutes **no release from `R-LSK-004`**, whose forbidden list names neither.

No wildcard, no prefix match, no directory-level relaxation; the two filters SHALL remain **byte-in-sync** with each other; and any file AG-20 adds that is not so named MUST still fail the guards. **`failure.go`, `cost_events.go`, `cost_events_test.go`, `stream_check_test.go` and `reconstruction_test.go` are each absent from AG-20's additions**, and each absence is deliberate: AG-20 MUST NOT edit any of them, and a filter entry would remove the guard that says so. Neither is any file under `backend/agent/src/ai/` or `backend/agent/src/agenttest/`. **No `agenttest` entry is added** — the filters do not govern that directory, and `agenttest` is byte-unchanged.
